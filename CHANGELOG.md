# Changelog

## 1.0.0 — 2026-11-22

Первый публичный релиз.

- Кнопка микрофона в панели инструментов поля ввода DSH.
- Фразовый стриминг: текст появляется после каждой паузы, запись не прерывается.
- Локальное распознавание faster-whisper `small` (`ru`, `int8`, CPU) с пунктуацией.
- Тёплый Python-процесс: модель загружается один раз на сеанс.
- Автоматическая установка venv, зависимостей и модели при первом запуске.
- Полностью офлайновая работа после установки (`local_files_only`).
- Вставка текста без автоотправки.
- Настройки: `model`, `threads`, `beamSize`, `dataRoot`, `pythonPath`.
- Локализация интерфейса: русский, английский, китайский.
