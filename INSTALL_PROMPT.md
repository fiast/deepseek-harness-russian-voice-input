# 🤖 Промпт установки для агента DeepSeek Harness

Этот файл — готовая инструкция для ИИ-агента внутри DeepSeek Harness. Скопируйте его
целиком в чат DSH (или дайте агенту ссылку на файл) — и агент установит плагин, проверит
окружение и сообщит результат.

Короткий вариант для вставки в чат:

```text
Установи плагин русского голосового ввода для DeepSeek Harness по инструкции:
https://github.com/fiast/deepseek-harness-russian-voice-input/blob/main/INSTALL_PROMPT.md
Действуй по шагам, проверяй результат и сообщи, когда кнопка микрофона будет готова.
```

---

## Инструкция для агента

Ты устанавливаешь локальный плагин русского голосового ввода в текущий профиль DeepSeek
Harness. Не меняй другие плагины, не отправляй данные пользователя и не запускай второй
сервер DSH. Выполняй шаги по порядку, после каждого проверяй результат.

### Шаг 0. Собери факты

1. Определи ОС, домашний каталог и доступный Python 3:

   ```powershell
   # Windows
   $env:USERPROFILE
   python --version
   py --version
   ```

   ```bash
   # macOS / Linux
   echo "$HOME"
   python3 --version
   ```

   Подойдёт Python 3.9–3.13. Если Python нет — остановись и сообщи пользователю,
   что нужен Python 3 (или путь к нему для настройки `pythonPath`).

2. Узнай URL текущего Web GUI DSH из контекста сессии (например,
   `http://127.0.0.1:50289`) — он понадобится для проверки статуса.
   Порт меняется при каждом запуске, не угадывай его.

3. Проверь доступ к сети: первый запуск скачивает venv-зависимости с PyPI и модель
   (~464 МБ) с Hugging Face. Если сети нет — сообщи, что установка возможна только
   при наличии интернета.

### Шаг 1. Склонируй репозиторий в постоянную папку

Не устанавливай плагин из временного каталога: папка должна пережить перезапуск DSH.

```powershell
# Windows
$dir = Join-Path $env:USERPROFILE ".dsh\bundles\ru-voice-input"
git clone https://github.com/fiast/deepseek-harness-russian-voice-input.git $dir
```

```bash
# macOS / Linux
dir="$HOME/.dsh/bundles/ru-voice-input"
git clone https://github.com/fiast/deepseek-harness-russian-voice-input.git "$dir"
```

Если папка уже существует — обнови её вместо клонирования:

```bash
git -C "$dir" pull --ff-only
```

Если файловая политика сессии запрещает запись вне workspace, склонируй репозиторий в
разрешённую папку и используй её путь дальше.

### Шаг 2. Установи бандл

Предпочтительный способ — инструмент `plugin_manager`:

- `action`: `install_bundle`
- `target`: **абсолютный путь** к склонированной папке (например,
  `C:\Users\<user>\.dsh\bundles\ru-voice-input`)

Если инструмент недоступен, используй CLI (затем бандл нужно включить в списке плагинов):

```powershell
dsh plugin --profile <профиль> add "link:<абсолютный путь>"
```

Ожидаемый результат: `application: "applied"`. Если вернулось `restart-required` —
попроси пользователя перезапустить DSH и продолжи после перезапуска.

### Шаг 3. Дождись подготовки распознавания

Плагин при первом запуске сам создаёт venv, ставит `faster-whisper` и `av<19`,
скачивает модель. Это занимает от нескольких минут до получаса в зависимости от сети.

Проверяй статус (подставь актуальный порт GUI):

```powershell
Invoke-WebRequest "http://127.0.0.1:<порт>/plugins/ru-voice/status" -UseBasicParsing |
  Select-Object -Expand Content
```

```bash
curl -s "http://127.0.0.1:<порт>/plugins/ru-voice/status"
```

Жди, пока не появится:

```json
{"ready":true,"warm":true,"model":"small"}
```

Опрашивай не чаще раза в 10–15 секунд, не блокируй пользователя. Если `phase` равен
`error`, прочитай поле `error` и перейди к разделу «Если что-то пошло не так».

### Шаг 4. Проверь регистрацию в интерфейсе

Через `cordis_inspect_query` (platform `client`, provider `Slots`, method `listSubTree`,
`root`: `conversation.input.right`) убедись, что среди occupants есть
`id: "ru-voice-input"` и `active: true`. Если occupant отсутствует — проверь, что бандл
включён (`plugin_manager`, `list_bundles`), и сообщи об этом.

### Шаг 5. Сообщи результат пользователю

Кратко напиши:

- плагин установлен и активен;
- кнопка микрофона находится в панели инструментов поля ввода, перед кнопкой отправки;
- говорите по-русски, после паузы ~0,7 с фраза появится в поле ввода;
- текст **не отправляется автоматически**;
- после первой установки интернет для распознавания не нужен;
- где менять настройки: `$DSH_HOME/profiles/<профиль>/cordis.patch.yml`, пример —
  `examples/cordis.patch.yml` в репозитории (`model`, `threads`, `beamSize`, `dataRoot`,
  `pythonPath`).

### Если что-то пошло не так

| Симптом | Действие |
|---|---|
| `Не найден Python 3` | Найди Python 3.9–3.13 и укажи его в `pythonPath` конфигурации плагина |
| `Не удалось подготовить распознавание` | Проверь текст `error` в статусе, доступ к PyPI/Hugging Face и место на диске |
| Долго висит `downloading`/`installing` | Это первая установка, дождись окончания; не перезапускай её параллельно |
| Ошибка `metadata_errors` | В venv попал PyAV 19; выполни `%USERPROFILE%\.dsh\plugin-data\ru-voice\venv\Scripts\pip install "av<19"` (плагин делает это сам) |
| `Доступ к микрофону запрещён` | Разреши микрофон для страницы DSH в браузере |
| Статус `ready: false` после 30 минут | Сообщи пользователю `phase` и `error`, предложи проверить сеть и диск |

Не удаляй `~/.dsh/plugin-data/ru-voice` без просьбы пользователя: там venv и модель,
без них потребуется повторная установка.
